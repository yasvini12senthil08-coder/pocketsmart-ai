# Phase 1: Brainstorming & Ideation - PocketSmart AI

## 1. Project Concept & Vision
* **Project Name**: PocketSmart AI
* **Core Vision**: A lightweight, browser-based AI smart planner that brings together everyday planning tasks—such as home budgeting, jewelry purchasing, and party organization—into a single, unified dashboard powered by the Google Gemini API.

## 2. Problem Identification
* **Scattered Tools**: Users typically have to juggle multiple disconnected applications (spreadsheets for calculations, event apps for parties, notes for budgeting).
* **High Learning Curve**: Existing financial software is often overly complex and rigid.
* **Lack of Instant Customization**: Traditional planners cannot adapt dynamically to individual user queries or custom budgeting goals.

## 3. Proposed Solution & Brainstormed Ideas
* **Single Prompt Interface**: Instead of multiple forms, provide one text box where users can type any planning goal.
* **AI-Driven Automation**: Leverage the Google Gemini API to instantly generate structured, professional advice, savings plans, and cost estimations.
* **Lightweight Architecture**: Use FastAPI and Jinja2 templates for fast local execution without heavy infrastructure requirements.
